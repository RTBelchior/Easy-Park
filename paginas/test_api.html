5️⃣ Verificar Base de Dados

Execute este SQL no phpMyAdmin para verificar se há dados: 
SELECT 'PARQUES' AS Tabela, COUNT(*) AS Total FROM parque
UNION ALL
SELECT 'UTILIZADORES', COUNT(*) FROM utilizadores
UNION ALL
SELECT 'HISTÓRICO', COUNT(*) FROM historico_acesso
UNION ALL
SELECT 'ENTRADAS HOJE', COUNT(*) FROM historico_acesso 
WHERE tipo_acesso='entrada' AND DATE(data_hora)=CURDATE();
